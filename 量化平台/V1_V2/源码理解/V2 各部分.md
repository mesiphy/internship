# 前端

```python 
frontend/
├── dist/               # 前端构建产物
├── node_modules/       # npm 安装后的依赖包目录
├── package-lock.json   # npm 依赖锁定文件

```
src/ 文件是主要修改的地方，其他文件夹都属于辅助文件

```python
src/
├── main.js        # 前端启动入口  前端应用的“开机按钮”：创建 Vue 应用，装上组件库、状态管理、路由，然后把应用显示到网页上
├── App.vue        # Vue 根组件 —— 是前端应用的最外层外壳：负责设置全局组件语言、提供页面显示出口、设置全局基础样式
├── router/        # 路由 —— 浏览器地址与VUE页面的关系
├── layouts/       # 整体页面布局   页面公共外壳
├── views/         # 业务页面 详细的布局页面设置
├── api/           # 后端接口封装
├── stores/        # 全局状态管理--- **放“跨页面共享状态”的地方**
├── utils/         # 工具函数
├── components/    # 可复用组件，目前为空占位
└── assets/        # 静态资源，目前为空占位

```


# 后端

```python
app/
├── __init__.py        Python 包标记文件，让 app 可以被 import
├── api/               API 路由层。接收前端 HTTP 请求，定义接口
├── config/            app 内部配置占位目录。当前主要配置不在这里，而在 V1/config/
├── core/              后端基础设施。配置读取、应用创建、日志、异常、枚举、统一响应格式
├── db/                数据库层。数据库连接、建表 SQL、Repository 数据访问代码
├── engine/            核心引擎层。回测、因子计算、策略信号、风控、因子研究等核心逻辑
├── plugins/           插件体系。因子插件、数据源插件、清洗器、通知器、ML/交易接口预留
├── schemas/           数据结构/校验层。Pydantic 请求体、响应体、字段类型校验
├── services/          业务服务层。编排 API 请求背后的业务流程，调用 engine和 repository
├── tasks/             定时任务层。APScheduler 调度任务，例如数据同步、因子计算、信号生成
├── utils/             通用工具函数目录。当前较轻，主要作为后续公共工具预留
├── __pycache__/       Python 字节码缓存，自动生成，可忽略
└── .DS_Store          macOS 自动生成的文件，可忽略
```

业务流程：
	前端请求进来
	  ↓
	api 接住请求
	  ↓
	services 编排业务
	  ↓
	engine 执行核心计算
	  ↓
	db 读写数据库

## 数据库管理
