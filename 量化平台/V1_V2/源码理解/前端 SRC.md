# VUE
vue文件主要结构：

在前端项目中的地位：


.vue 页面关心：什么时候请求、拿到数据后怎么展示
.js API 文件关心：请求哪个接口、用 GET 还是 POST、参数怎么传

.js   = 纯逻辑文件
.vue  = 页面/组件文件，里面可以同时写结构、逻辑、样式
