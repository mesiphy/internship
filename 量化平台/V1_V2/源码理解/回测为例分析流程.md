
```text

用户点击“开始回测”
  ↓
Backtest.vue 里的 runBacktest() 被触发
  ↓
页面整理表单数据 payload
  ↓
调用 createBacktest(payload)
  ↓
backtest.js 发送 POST 请求
  ↓
后端 api/v1/backtest.py 接收到请求FastAPI 把请求内容包装成body: BacktestCreateRequest
  ↓
后端校验请求数据 Schemas/ 负责校验请求格式是否正确
  ↓
调用 BacktestService.submit() api层在调用
  ↓
BacktestService 创建回测任务，写入数据库
  ↓
BacktestEngine 后台线程开始跑回测
  ↓
后端立刻返回 task_code 给前端
  ↓
前端开始轮询任务状态

```

### 调用 BacktestService.submit()
class BacktestService 的理解：
  api 层的 backtest 进行调用，实例化类，并调用函数 submit，submit 把前端的参数传入某些函数，并调用引擎后台进行计算，submit 返回taskcode到api层，一层层返回taskcode
  **负责回测任务编排，但是需要由api调用**

```text
前端 form/dateRange
  ↓
payload JS 对象
  ↓
HTTP JSON 请求体
  ↓
BacktestCreateRequest body
  ↓
BacktestService.submit() 参数
  ↓
backtest_task pending 记录
  ↓
后台线程参数
  ↓
BacktestEngine.run()
  ↓
backtest_* 结果表 + result_data
  ↓
HTTP JSON 响应
  ↓
前端 res / historyList / summary / navRows / orders
  ↓
页面表格和图表

```
