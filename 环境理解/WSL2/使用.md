在这些情况下，建议执行 `wsl --shutdown`：

你要彻底释放内存和后台进程；  
WSL、VS Code、Docker、网络代理出现异常；  
你准备重启/关机前想干净退出；  
你修改了 `.wslconfig`；  
你发现 `wsl -l -v` 里 Ubuntu 一直是 `Running`，但你已经不用它了；  
Docker Desktop / VS Code Remote WSL 卡住或连接异常。
